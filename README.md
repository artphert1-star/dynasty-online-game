# Dynasty Online v1.3

อัปเดตตาม Dynasty Rulebook v1.3 โดยคงสถาปัตยกรรมเดิม: `server/engine.js` เป็นกติกาและสถานะเกม, Express + Socket.IO รับคำสั่งและส่งมุมมองเฉพาะผู้เล่น, `client/index.html` เป็นหน้าเว็บภาษาไทย ไม่มี framework หรือฐานข้อมูลใหม่

## เปิดเกมบน Windows

แตก ZIP ก่อน แล้วดับเบิลคลิก `Start-Game.cmd` เปิด http://localhost:3000 ในเบราว์เซอร์ และเปิดหน้าต่างเซิร์ฟเวอร์ค้างไว้ กด Ctrl+C เมื่อต้องการหยุด ไม่ต้องใช้ Render หรือ Vercel

ชุด Windows มี dependencies พร้อมใช้ ตัวเปิดเกมค้นหา Node.js 20 ขึ้นไปที่ติดตั้งอยู่ หรือ Node.js ของ Codex ในเครื่องนี้ หากเครื่องอื่นไม่มี Node.js ให้ติดตั้งก่อนหนึ่งครั้ง ไฟล์ชุดซอร์สที่ไม่มี dependencies จะติดตั้งด้วย npm ในครั้งแรก

สร้างห้อง เพิ่มเพื่อนหรือบอทให้ครบ 3–6 คน กดเริ่มเกมเพื่อเลือกผู้นำ ใครเลือกก่อนจะได้การ์ดนั้นก่อน เลือกแล้วเปลี่ยนไม่ได้ บอทจะเลือกจากใบที่เหลือเมื่อผู้เล่นเลือกครบ เกมเริ่มยุคแรกอัตโนมัติ

ถ้าเล่นกับเพื่อนใน Wi-Fi/LAN เดียวกัน ให้เพื่อนเปิด IP ของเครื่องเซิร์ฟเวอร์พร้อมพอร์ต 3000 เช่น `http://192.168.1.20:3000` แล้วใส่รหัสห้องที่เจ้าของส่งให้ `localhost` ใช้ได้เฉพาะเครื่องที่รันเซิร์ฟเวอร์ หาก Windows ถามเรื่องเครือข่าย ให้อนุญาตเครือข่ายส่วนตัวเพื่อเล่นใน LAN

หากพอร์ต 3000 ถูกเกมเวอร์ชันเดิมใช้อยู่ ให้หยุดหน้าต่างเกมเดิมก่อนเปิดชุดใหม่ เพื่อนที่อยู่อินเทอร์เน็ตคนละเครือข่ายต้องมีช่องทางเข้าถึงเครื่องเซิร์ฟเวอร์เพิ่มเติม การเปิด local server อย่างเดียวไม่ได้สร้างลิงก์สาธารณะ

## รันจากซอร์ส

ติดตั้ง Node.js 20 ขึ้นไป รันในโฟลเดอร์ `server`:

```sh
npm install
npm start
```

รองรับ pnpm พร้อม `server/pnpm-lock.yaml` ที่ผ่านการทดสอบ ใช้ `pnpm install --frozen-lockfile` เว็บและ Socket.IO อยู่บนเซิร์ฟเวอร์เดียวกัน

## สิ่งที่เพิ่มใน v1.3

- เลือกผู้นำ 8 ใบหลังเริ่มเกม ผู้เลือกก่อนมีสิทธิ์ก่อน เซิร์ฟเวอร์ปฏิเสธการเลือกซ้ำ
- ผิดบุญคุณหักบารมี 2 ส่วนขาดเป็นโทษค้าง บารมีใหม่จากทุกแหล่งชำระโทษก่อน บารมีสุทธิใช้เรียงตา คิดคะแนน และตัดสินเสมอ
- บุญคุณต้องระบุเป้าหมายและทิศทางของวิ่งเต้น หรือข้อความสัญญาอื่น ระบบตรวจวิ่งเต้นจากการเปิดจริง สัญญาอื่นให้ผู้ถือยืนยันผล
- หลังลักพาตัว ผู้นำคุ้มครองจนเหยื่อจบตาในยุคถัดไป แม้ได้ทายาทคืน การจับซ้ำเริ่มนับใหม่
- กบฏใช้ทหารได้ แต่ซื้อเต๋าด้วยเงินไม่ได้
- ผลิตทายาทได้เฉพาะไม่มีทายาทและไม่มีทายาทถูกกัก รับบุตรบุญธรรมเมื่อกองหมดไม่เสียเงินแต่เสียช่อง
- เสมอการจัดตาทอยใหม่เฉพาะคนที่เสมอ ถ้าคะแนนและตัวตัดสินทุกอย่างเท่ากันให้ชนะร่วมกัน

## กติกาที่เปลี่ยน

- เหตุการณ์และเงินเดือน → เจรจา → วางซองลับ → วนตา → ปลายยุค
- เจรจา 2 นาที หรือ 3 นาทีเมื่อมี 5–6 คน ทุกคนกดพร้อมเพื่อข้ามเวลาได้
- ใส่ซอง 0–จำนวนช่อง คว่ำเฉพาะสืบ ลักพาตัว ลอบสังหาร วิ่งเต้น และป้องกัน เลือกเป้าหมายตอนเปิด
- ยศต่ำก่อน บารมีสุทธิสูงก่อน เสมอทอย d6 ใหม่เฉพาะผู้เสมอ ล็อกลำดับทั้งยุค ช่องเปิดเผยล็อกตามยศตอนวางซอง
- เปิดเผยและปฏิบัติการลับทำในตาตัวเอง แต่ละชนิดครั้งเดียว ยืนยันจบตาเอง
- วิ่งเต้นเปิดตามลำดับตา ผู้ขอเลือกทหารและเงินหลังวิ่งเต้น ผู้ป้องกันเลือก Guard และเงินหลังเห็นเงินของฝ่ายโจมตี
- ทอยและแก้ผลทันทีที่เซิร์ฟเวอร์หลังยืนยัน หน้าเว็บแสดงลูกเต๋าจริง ระบบ replay ทั้งยุคเดิมถูกแทนด้วยหน้าตอบสนองตามการกระทำ
- ผู้นำคุ้มครองหลังทายาทถูกลักพาตัวสำเร็จจนเหยื่อจบตายุคถัดไป และคุ้มครองหลังขึ้นครองจากผู้นำตายจนจบยุค ตระกูลที่ผลัดบัลลังก์ยังทำตาต่อได้
- ลอบสังหารทอย 0 ให้เหยื่อความลับค่า 3 สำเร็จผู้ลงมือเสียบารมี 1 สืบชนะขาดอย่างน้อย 2 ให้ความลับค่า 2
- ความลับใช้รีดไถหรือปิดปาก ปิดปากสุ่มซองเฉพาะในตาตัวเอง จำกัดถือ 3 ใบและใช้ 1 ใบต่อยุค กอง 30 ใบตามสัดส่วน 15/10/5 ใบที่ทิ้งกลับเข้ากองของค่านั้น
- ค่าไถ่ไม่มีราคาตายตัว ไม่มีคืนอัตโนมัติ ส่งข้อเสนอเงิน ความลับ การปล่อยตัว และบุญคุณ ผู้รับยอมรับก่อนส่งมอบ
- บุญคุณรองรับรับโทเคน เรียกใช้ ตรวจวิ่งเต้นจริง ยืนยันสัญญาอื่นโดยผู้ถือ และลงโทษผิดสัญญา 2 บารมีพร้อมโทษค้างปลายยุค
- เลือกทายาทจาก Fertility และเลือกใบสำรองเมื่อ Fertility 3 ผู้ถูกสืบเลือกใบความลับที่จะถูกทำลายได้
- ทอยวัยก่อนติดสินบน ปราบกบฏเลือกทหาร ซื้อเต๋าด้วยเงินไม่ได้ เงินติดสินบนรวมไม่เกิน 2 ต่อยุค
- แต่งงานตามตา ไม่มีทอยแย่ง ขึ้นยศฟรีจากภรรยาไม่เพิ่มบารมี เว้นขึ้นไม่ได้จึงได้บารมี +2 ตามข้อ 14.3
- ไม่ใช้โมดูลราชสำนัก ลูกลับ ตัวลวง เปิดโปง บีบบังคับ และตราประทับในเกมหลัก

## UX/UI

แสดงเฟส ลำดับตา ช่องที่เหลือ ซองของตัวเอง การ์ดคู่แข่งที่เปิด และผู้นำที่คุ้มครอง มีหน้าตอบสนองสำหรับวิ่งเต้น ป้องกัน ขอเลื่อนยศ กบฏ เลือกทายาท และทำลายความลับ รองรับมือถือ โฟกัสคีย์บอร์ด ลดแอนิเมชัน และคู่มือ v1.3 ใช้ Socket.IO client จากเซิร์ฟเวอร์แทน CDN

## ทดสอบ

```sh
cd server
npm test
npm run sim -- 500
```

ทดสอบกติกา ข้อมูลลับ reconnect สิทธิ์เจ้าของห้อง และ Socket.IO จริง รวมจำลองบอท 3–6 คน ตรวจหน้าเว็บ 1440 และ 390 พิกเซลด้วย `ui-smoke.cjs` (QA ต้องมี Playwright และ Edge ไม่จำเป็นต่อการเปิดเกม)

## ขอบเขตการใช้งาน

สถานะห้องอยู่ในหน่วยความจำตามสถาปัตยกรรมเดิม เซิร์ฟเวอร์รีสตาร์ตแล้วห้องหาย การ reconnect ใช้รหัสผู้เล่นและ session token ในเบราว์เซอร์ ผู้เล่นกลับด้วยเบราว์เซอร์เดิมได้ การตัดสินใจรอเจ้าของตายืนยัน ไม่มีระบบเล่นแทนคนที่ขาดการเชื่อมต่อ

แลกของสองทางใช้ข้อเสนอแยกกัน และผูกคำสัญญาด้วยบุญคุณตามกติกา ไม่บังคับค่าไถ่ราคาใด ถ้ากองทายาทและกองทิ้งไม่พอจะจั่วเฉพาะใบที่เหลือ ไม่สร้างเพิ่มเกิน 24 ใบ เสมอ d6 ในการจัดตาทอยใหม่เฉพาะผู้เสมอ

ยังต้อง playtest กับคนจริง ผลจำลองบอทตรวจการทำงานจนครบ ไม่ใช่หลักฐานความสมดุล งานนี้ยังไม่ได้ deploy ออนไลน์
